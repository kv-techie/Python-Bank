## 🚀 **Quick Start in 3 Steps**

### **Step 1: Run Setup Script**
```bash
# Windows
setup.bat

# macOS/Linux
chmod +x setup.sh
./setup.sh
```

### **Step 2: Start Backend**
```bash
python app.py  # Terminal 1
```

### **Step 3: Start Frontend**
```bash
cd frontend
npm start      # Terminal 2
```

**👉 Application opens at http://localhost:3000**
